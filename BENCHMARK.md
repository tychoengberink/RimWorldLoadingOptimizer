# RimWorld Loading Optimizer: benchmark

RimWorld Loading Optimizer 5.5 pre-release, measured on 20 November 2026 with one start per scenario; support for seven other mods and the startup report were switched on.

| Time | Scenario | Platform |
|---|---|---|
| 89.3 s (1:29) | Cold start to the main menu: Missile Girl's XML cache is not used, as after a mod list change | Mac (Apple M5 Pro, 24 GB), macOS, RimWorld 1.7.5014 with 1,553 mods |
| 72.6 s (1:13) | Warm start to the main menu: a normal start | Mac (Apple M5 Pro, 24 GB), macOS, RimWorld 1.7.5014 with 1,553 mods |
